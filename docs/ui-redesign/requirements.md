# RepoAUDT Mac の兄弟アプリ UI 要件

- NetworkPNTR Mac / NetworkISPR Mac と同じ標準サイドバー、ツールバー、システムフォント、意味色を採用する。
- 初期画面は保存済みリポジトリのダッシュボード。URL入力を主操作として示す。
- 監査結果、構成図、実行フローを左側から切り替える。選択リポジトリを維持する。
- 詳細は必要時に表示する。日英切替、既存解析、レポート、設定、検索を利用できる。
- 読込中、保存データなし、読込失敗を区別する。未実装のPR操作や解消確認を完成済みとして表示しない。
- ネイティブビルドと実アプリで初期画面、画面切替、詳細、設定、日英、狭いウインドウを確認する。
