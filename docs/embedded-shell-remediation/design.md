# Design

Use the verified authorization finding as the basis for the repair. The retired endpoint returns HTTP 410 without a shell or subprocess. Keep the right-hand pane and shortcut for copying inspection commands. Finding details retain the diff and clipboard control. Remove their automatic run action and render command text as text. Lazyweb's GitHub code-review reference places the suggested change in the review context with an explicit action. This repair keeps that review-and-decide sequence in the audit inspector.
