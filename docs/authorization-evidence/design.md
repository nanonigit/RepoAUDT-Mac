# Authorization evidence design

Adapt ARTEX finding provenance to static source. Each finding records evidence anchored to one verified GitHub commit. A narrow Python AST rule inspects a direct HTTP POST handler with an optional Origin check and a request-derived command passed to a privileged operation. Unknown guards or dispatch logic keep the rule from making a finding.

The proposed remediation removes the privileged route body and returns HTTP 410. Build a unified diff from the exact source, parse the proposed result and confirm the rule no longer matches. The existing finding detail already presents evidence, links and diffs. There is no new UI design. Lazyweb is out of scope.

MITRE [CWE-862](https://cwe.mitre.org/data/definitions/862.html) supplies the weakness classification.
